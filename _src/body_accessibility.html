Accessibility Statement

Cherish Moments Decor is committed to making this website usable by everyone, regardless of ability or technology. This site was built with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA in mind, including:

Keyboard-accessible navigation, menus, galleries, and forms; visible focus indicators; strong color contrast; descriptive alternative text for meaningful images; labeled form fields with clear validation messages; support for reduced-motion preferences; and screen-reader-friendly controls throughout.

Ongoing Effort

Accessibility is an ongoing effort. If you encounter any barrier while using this website — or need assistance with any content — please contact us and we will gladly help and address the issue.
